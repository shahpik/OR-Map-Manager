# CONTRIBUTING

This document contains details for contributing to the or-core repository.

## Pull Requests

For PRs, please copy the template below into the Description field.

### Pull Request Template

```markdown
### Purpose

<High level summary of purpose of PR>

### Linked Issues

<link to JIRA issues>

### Why?

<What is the motivation for this>

### Description

<Detailed description of changes>

### Change List

#### Added

<List of added code>

#### Updated

<List of updated code>

#### Deleted

<List of deleted code>

### Test Results

<Link to CI or similar>

### PR Checklist

Does this change

- Meet the design?
- Have appropriate test coverage?
- Have passing tests?
- Have a good commit message? - clear, correct tense, short
- Have docstrings?
- Have satisfactory code quality?

```
